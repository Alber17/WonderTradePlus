# Roadmap

Ideas pendientes para versiones posteriores:

- Compatibilidad NeoForge basada en el mismo motor de reglas.
- Integración opcional con LuckPerms para nodos por jugador.
- Importar/exportar pool y comandos administrativos para retirar entradas concretas.
- Historial consultable de intercambios.
- Reglas por mundo/dimensión, horario, coste de economía o permisos individuales.
- Pruebas de integración automatizadas sobre servidor de prueba con Cobblemon.

Ya implementado: GUI de equipo y PC, vista del pool, anuncios por categoría.
