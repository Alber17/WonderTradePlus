# Roadmap

Ideas pendientes para versiones posteriores, no implementadas en 0.1.0:

- GUI de inventario/estación de Wonder Trade.
- Compatibilidad NeoForge basada en el mismo motor de reglas.
- Integración opcional con LuckPerms para nodos por jugador.
- Importar/exportar pool y comandos administrativos para inspeccionar/retirar entradas.
- Historial consultable de intercambios.
- Reglas por mundo/ dimensión, horario, coste de economía o permisos individuales.
- Pruebas de integración automatizadas sobre servidor de prueba con Cobblemon 1.8.4.
